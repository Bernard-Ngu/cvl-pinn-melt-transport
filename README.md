# Mantle flow and melt transport beneath the Cameroon Volcanic Line

Code and data for the physics-informed neural network that recovers
asthenospheric flow and hydrous melt transport beneath the Cameroon Volcanic
Line from shear-wave tomography and a gravity-derived lithospheric geometry.

Everything here runs on numpy, scipy and matplotlib. The automatic
differentiation is written from scratch in `code/autodiff.py`, because PyTorch
and JAX were not installable in the environment this was developed in; the
consequence is that the whole model is readable in a few hundred lines and has
no framework to version against.

## Quick start

```bash
pip install -r requirements.txt
./run_all.sh                  # grids.npz -> trained model -> figures (~35 min)
code/run_map.sh               # Fig. 1, the tectonic map
```

`run_all.sh` trains the three lithospheric treatments reported in the paper —
free (`A`, the model reported), locked (`L`) and slip (`S`) — at 5 000
iterations each, roughly ten minutes apiece. Everything after the training
takes seconds.

## What is not in the repository

Two kinds of file are left out because they are derived and large. Both are
regenerated by `run_all.sh`.

| file | size | made by |
|---|---|---|
| `data/background.npz` | 65 MB | `code/fields.py`, about a minute |
| `runs/solution_{A,L,S}.npz` | 47 MB each | `code/train.py`, during training |

The trained weights (`runs/params_*.npz`, 140 kB each) **are** included, so the
solutions can be regenerated without retraining if you prefer:

```python
import sys; sys.path.insert(0, "code")
import train, fields
p, hist = train.load_params("A", 64, 5)
train.evaluate(p, fields.Background(mode="selfconsistent"), 1e-7, "A", lid="none")
```

## Figures

`code/make_figures.py` draws Figs. 2–13 at the type size the figures were
originally laid out for. `code/rebuild_figures.sh` redraws the same figures at
publication type size — axis labels 32 pt, axis values 28 pt — enlarging the
canvases to match and thinning the tick counts where the numbers would
otherwise collide. Sizes are set in that one script:

```bash
code/rebuild_figures.sh              # all of them
code/rebuild_figures.sh --only 7     # one, by manuscript figure number
CVL_LABEL_SIZE=28 code/rebuild_figures.sh
```

`code/extract_figures.sh` collects the figures under the numbers the paper
uses, since the file names do not match them (`fig1_setting` is Fig. 2, and so
on); the mapping is in that script.

Fig. 1 is drawn by `code/run_map.sh`, which uses PyGMT if it is installed, GMT
if not, and falls back to matplotlib without relief if neither is present.

## Reviewer experiments

`code/exp_run.py` and its companions hold the two experiments reported in Section 2.11: a
sweep over {3, 5, 7} hidden layers by {32, 64, 128} neurons, and an ablation
that removes the one-sided buoyancy-work penalty from the objective while
leaving everything else unchanged.

```bash
code/run_experiments.sh
```

The two plots are committed, in `experiments/figures/`:

* `figA1_architecture_sweep` — the momentum residual over the 3 x 3 grid with
  the reported network marked, all five residuals configuration by
  configuration, and the nine training histories as an envelope.
* `figA2_energy_constraint` — the five residuals with and without the
  buoyancy-work penalty, and the work integral itself, whose sign is the
  result.

Re-running the script overwrites them. Every configuration trains from the
same seed with the same batch size,
sampling split, curriculum, optimiser and schedule, and is then evaluated on
one fixed set of 6 000 collocation points, so the rows of the resulting table
are comparable. Results land in `experiments/results/`, as JSON and as a formatted table, and the plots
in `experiments/figures/`.

The ablation is the substantive one: with the energy constraint removed, every
conservation residual is marginally *lower* — by the usual measure the better
converged run — while the buoyancy-work integral turns negative, which is
impossible for a steady creeping flow driven by buoyancy through work-free
boundaries. Minimising residuals is necessary but not sufficient.

## Model, in brief

A fully connected network of five hidden layers of 64 neurons with tanh
activations and 18 063 trainable parameters. Five inputs per point: three
normalised coordinates, the equilibrium melt fraction scaled by the reference
porosity, and the temperature scaled as (T − 1600 K)/300 K. Fifteen outputs:
three solid velocity components, dynamic and compaction pressures, porosity,
six independent deviatoric stress components and three components of the Darcy
flux.

The mixed first-order formulation means every residual contains first
derivatives only, which halves the depth of the differentiation graph and
avoids the accuracy loss that second derivatives of a tanh network incur where
the viscosity contrast is sharpest. Boundary conditions are imposed by
construction rather than penalised: raw outputs are multiplied by masks that
vanish where the corresponding component must vanish, so they hold to machine
precision for any value of the weights. The lithosphere is removed from the
flow problem by a mask of the same kind, built on the signed distance to the
lithosphere-asthenosphere boundary.

Training uses Adam at an initial learning rate of 2 × 10⁻³, cosine-decayed to
one per cent of that over 5 000 iterations, with 2 600 collocation points
resampled every iteration: 30 per cent from within the melting region, 45 per
cent above 300 km, 25 per cent uniform over the box. Viscosity and permeability
are lagged at the current iterate rather than differentiated, the standard
Picard treatment for a contrast of this size.
